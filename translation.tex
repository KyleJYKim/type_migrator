\subsection{Translation in Fields}

Let $\tau$ range over the right-hand side type of field types, that is, $\tau$ is either $\TST$ or $\ifset\TST$. We consider lists whose elements are of the form \texttt{\ETK\,\,=>\,\,$\tau$}. Given such a list $L$ we write $\ETK\in L$ is there exist $\tau$ such that the element \texttt{\ETK\,\,=>\,\,$\tau$} belongs to $L$. We denote by \textsf{Empty} the lists that maps all the non-singleton keyttypes to \texttt{not\_set()}. 

Given two field lists $L_1$ and $L_2$, we write $L_1 \oplus L_2$ the list obtained by adding to $L_1$ all the fields elements $\ETK\fto\tau$ of $L_2$ such that $\ETK\not\in L_1$. Formally:
\[\begin{array}{rcll}
   L_1 \oplus \texttt{[\,]} &= & L_1 \\
   L_1 \oplus \texttt{[}\,\ETK\fto\tau, L_2\texttt{]} &=& L_1 \oplus L_2 & \textsl{if }\ \ETK\in L_1 \\
   L_1 \oplus \texttt{[}\,\ETK\fto\tau, L_2 \texttt{]} &=& \texttt{[}\,\ETK\fto\tau, L_1\texttt{]}\oplus L_2  & \textsl{if }\ \ETK\not\in L_1 \\
\end{array}\]
We then define \textsf{map($L$)} as the map type whose field list is $L$. Then we have 
$\dsb{\map{\texttt{\TSF$_1$,\,...,\,\TSF$_n$}}} =\textsf{map($\bigoplus_{i=1}^{n}\dsb{\TSF_i}$)}$. If we want a saturated map type (i.e., a map type that specifies all the possible keytypes), then we have $\dsb{\map{\texttt{\TSF$_1$,\,...,\,\TSF$_n$}}} =\textsf{map($\bigoplus_{i=1}^{n}\dsb{\TSF_i}\oplus\texttt{Empty}$)}$
